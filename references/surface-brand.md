# 品牌与商业面

品牌面（官网、落地页、作品集、lookbook、发布页）要让人记住这是谁；商业面（商详、列表、购物车、结算）要让人放心完成一次购买。两者共用本页的工艺底线，结构各走各的。

## 1. 页型决定结构

一个页面先回答它要做什么，再决定结构，四种页型是四种不同的论证方式：

| 页型 | 页面要做的事 | 结构骨架 |
| --- | --- | --- |
| 落地页 / 发布页 | 让人理解一个新东西 | 一句主张 → 它解决的事 → 怎么工作 → 证据 → 行动 |
| 作品集 / 工作室 | 证明做过、做得好 | 代表作先行 → 过程与角色 → 方法 → 联系 |
| lookbook / 系列 | 让人想要 | 大图节奏 → 细节特写 → 场景 → 购买入口 |
| 品牌站 | 讲清楚这是谁 | 态度 → 产品线 → 故事 → 新闻与招募 |

同一页型里再按内容调整段落顺序与密度，让同类页面之间也有差异。

## 2. 灵魂来自五轴组合

身份的可识别特征由五个正交轴各自做一个明确选择组合而成：构图与信息组织（对称/非对称、单栏/多栏、留白量）、排版节奏（字族对比、字号级差、行长）、图像语言（摄影/插画/3D/纯排版、裁切方式）、色与材质（主色关系、中性色色相、纸面/玻璃/实底）、交互与动效表达（节制/表演、滚动驱动/点击驱动）。每轴写下选了什么、为什么，身份卡据此成立；重复任务时在五轴上换至少两项，让每次产出之间有实质差别。

## 3. 工艺底线

- 中性色带色相：背景、纸面、边框、弱文字从同一色相的中性阶取，纯 `#fff` / `#000` 只在用户指定时用。
- 边框 1px 细线；阴影写完整的 offset/blur/spread/色值，层级分明。
- 文字对比正文 4.5:1、大字 3:1；标题字距随字号增大收紧。
- 字体选择写出理由：衬线/无衬线/等宽各承担什么角色，默认字族被选中也要能说出为什么。
- 数字与指标有来源，示例数据明确标注。
- 页面骨架里有图像位（hero、画廊、商品图、封面、空态）时给出图像方案；生成或从网络获取图像前先说明数量与来源，等用户同意再执行；真的不需要图像时写 `none` 和一句原因。

## 4. 品牌面的动效与奇观

把“动什么”与“怎么实现”分开，按[动效编排](motion.md)选路线。一个页面一条主叙事动效承载表达，其余动效服务于状态与反馈；用四拍（进场、反馈、状态变化、离场）代替单个 hero 大动效加通用淡入。需要 WebGL/Canvas/GSAP 引擎时写明资源成本与静态回退，弱设备与减少动效下页面完整可读。

## 5. 商业面骨架

- **商详（PDP）**：主图组 → 标题与价格 → 规格选择 → 主行动 → 详情与参数 → 评价 → 相关推荐；价格含税、运费与到货时间在行动按钮附近直接可见。
- **列表（PLP）**：筛选与排序 → 结果数 → 商品卡（图、名、价、关键属性、状态）→ 分页或加载更多；筛选条件可一眼看到并可逐个移除。
- **购物车与结算**：数量与小计实时更新 → 优惠与运费分别列出 → 支付方式 → 确认；附加服务默认未选，取消或返回与继续同样明显，总价在每一步一致。

## 6. 平台与密度

桌面按 [params-web](../data/params-web.json)，手机按 [params-h5](../data/params-h5.json)：手机上主行动放拇指区，商详的规格与购买入口吸底并处理安全区，画廊用横向滑动并保留宽高比占位。
