# 状态与动作：逐入口填参数

## 1. 先找真实事件

1. 从功能表取入口、handler、输入参数与结果 DOM。
2. 写默认 → 按下 → 请求中/切换 → 成功/失败的状态转换，取项目支持的状态。
3. 记录关闭、返回、重试时草稿、滚动、模型、来源与焦点如何恢复。

## 2. 做状态表

| 状态 | 实现动作 | 要记录/检查 |
| --- | --- | --- |
| 默认 | 按钮/链接/输入使用语义元素 | 标签、尺寸、背景与前景 token |
| 悬停 | 只改变当前控件表面或辅助提示 | 指针可用，触控也有主要入口 |
| 焦点 | outline 2px，offset 2px 起步 | Tab 顺序、可见色值、关闭归还位置 |
| 按下 | 立即更新按下表面/scale | 反馈和 handler 均在点击时触发 |
| 选中 | aria-current/selected 配连续指示 | 业务选项和视觉值一致 |
| 加载 | 原位置禁重复提交、保留宽高 | 请求/任务 ID、真实进度或等待说明 |
| 空/失败 | 显示原因与原有恢复按钮 | 保留输入、可重试或返回 |
| 成功 | 内容/来源/记录当场更新 | 显示与实际结果字段一致 |

适用状态逐项填写，静态文字不套按钮状态。触控入口按目标平台设置常用 44px 或 48px 命中区域；指针界面的小图标可扩点击区域，按项目标准核对。

## 3. 为每处点击填动作表

| 字段 | 填什么 |
| --- | --- |
| trigger | 具体控件和 click/keydown/submit |
| immediate | 按下表面和业务状态即时变化 |
| target | 实际 DOM/组件，受影响对象 |
| property | transform/opacity/indicator 等具体属性 |
| from / to | 位移 px、scale、opacity 等起止值 |
| enter / exit | ms 单值 |
| easing | CSS easing 或实际弹簧参数 |
| result | 字段、来源标签、路由或结果 DOM |
| interruption | 连按 5 次、旧请求、关闭途中如何处理 |
| reduced_motion | 最终状态直接呈现 |

## 4. 先采用一组可调参数

| 动作 | 起始参数 | 接到什么结果 |
| --- | --- | --- |
| 按下/松开 | scale 1→0.98，80ms；恢复 140ms | handler 立即发出，结果不等待动画 |
| 导航切换 | 指示块从当前位置到目标，200ms | aria-current 与真实路由/选项同步 |
| 小菜单展开 | opacity 0→1、scale 0.98→1、Y 4→0px，180ms | 首项可聚焦；关闭 120ms |
| 详情面板 | opacity 0→1、Y 8→0px，240ms | 真实详情呈现；退出 160ms |
| 选用素材 | 来源标签出现 160ms，轻移 4→0px | 原 draft 合并/来源绑定按契约更新 |
| 更换记录 | 内容交叉淡化 180ms | 旧内容换成新请求的实际记录 |

进入曲线可先用 `cubic-bezier(.2,.8,.2,1)`，退出先用 `cubic-bezier(.4,0,1,1)`。范围调到单值写入项目 motion token。形状变化保留同一个对象；内容变化才做交叉淡化。

## 5. 把反馈接成因果链

1. 导航：点击菜单 → 当前指示移过去 → 内容/路由变化。只移动指示的设计演示在交付说明标清。
2. 选素材：点击“选用” → 已选状态 → 输入附近出现实际名称/来源 → 原草稿按既有合并策略处理。
3. 模板详情：点击“角色关系” → 同一本书的对应 section → 关闭回到原入口。
4. 浮层从触发点方向展开；同一段动作保持同一方向，退出回到原位置。
5. 一页优先打磨 1–2 个关键结果时刻。首次出场可选一次 120–180ms，不在恢复页面时重播；高频阅读内容保持稳定。

## 6. 确定实现方式

1. 常用按下/展开用现有 CSS transition；共享位置过渡沿用项目已有能力，复杂可打断编排再用 WAAPI/现有动效库。
2. 线条绘制用 SVG；材质用项目表面组件；需要逐像素或大场景时再评估 Canvas/WebGL。
3. 读取减少动效与指针能力，按每个效果分支设置终态。减少动效改变时取消运行中的动画和装饰循环。
4. 尺寸读取与写入分批；RAF、事件和观察器在卸载/关闭时清理。异步结果按 request ID 或取消信号隔离。
5. 连按 5 次、开关 3 次、动画中关闭、键盘选择各实际操作；最终选择和焦点必须正确。

## 7. 输入、弹层与长任务

1. 输入保留标签、草稿、附件和模型；错误在相关区域显示，先验证原 selector/hook。
2. 模态层管理 inert/背景滚动、焦点 trap、Esc、焦点归还；菜单与非模态面板按各自语义处理。
3. 长任务用真实状态列步骤、结果和现有干预动作。停止点击立即呈现“请求停止”，实际停止确认后才呈现“已停止”。
4. 工具调用、队列、权限、价格和用量用现有字段；状态空缺写明待获取，恢复入口接既有事件。
