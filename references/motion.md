# 动效编排（横切）

先定真实状态再定动画：每个入口先写“触发 → 即时反馈 → 业务状态 → 结果 → 关闭/返回”，动效只服务这条链。微观参数（按下、导航指示、下拉、面板的时长与曲线）见[状态与动作](interaction.md)，本页管页面级编排与实现路线。

## 1. 四拍

一个页面的动效按四拍写表，每拍写清对象、属性与时序：

| 拍 | 做什么 | 例 |
| --- | --- | --- |
| 进场 | 让内容按阅读顺序到位 | 标题 → 正文 → 操作，间隔 40–60ms，各 200–240ms |
| 反馈 | 回应用户动作 | 按下 `scale(0.98)` 80ms 进、140ms 回 |
| 状态变化 | 让数据与状态的改变可追踪 | 数值变化 300ms 补间，列表项增删位移补间 |
| 离场 | 退出比进入快 | 面板退出 160ms，淡出先于位移结束 |

一个页面只有一条主叙事动效承载表达（滚动驱动的展开、转场、材质变化），其余动效都属于四拍里的反馈与状态。

## 2. 动什么与怎么做分开

先定效果族，再按成本选最低一档够用的实现路线：

| 效果族 | 典型形态 | 首选路线 |
| --- | --- | --- |
| 状态转场 | 列表增删、Tab 切换、展开折叠 | CSS transition / View Transitions |
| 滚动叙事 | 分段固定、进度驱动显隐 | 原生 scroll-driven animation |
| 空间镜头 | 推进、平移、视差 | CSS 3D + scroll-driven；复杂编排用 GSAP |
| 文字动效 | 逐字/逐行入场、字重变化 | WAAPI 或 GSAP SplitText 类 |
| 图像变换 | 裁切、放大、揭示 | CSS clip-path / mask + transition |
| 几何构建 | 线条生长、图形拼合 | SVG stroke-dash + WAAPI |
| 物理惯性 | 拖拽回弹、滚动吸附 | 原生 scroll-snap；拖拽用 pointer events + 缓动 |
| 粒子与流体 | 背景粒子、流体材质、着色器 | Canvas / WebGL（shaders 库） |
| 氛围 | 渐变呼吸、光斑移动 | CSS keyframes，低频低幅 |
| 共享元素 | 卡片放大成详情 | View Transitions / FLIP |

路线由低到高：CSS → 原生 scroll-driven → View Transitions/WAAPI → GSAP → Canvas/WebGL → CSS 3D 空间。四行 CSS 能做的事不引 60KB 库；引擎类路线写明资源成本、首帧时间与静态回退。

## 3. 记录与连按

每条动效记 `property / from / to / duration / easing / delay`，写进执行表第 8 节。连按 5 次的处理：最后一次选择生效，旧请求取消或忽略，动画从当前值接续。

## 4. 减少动效与弱设备

`prefers-reduced-motion: reduce` 下直接呈现结果态，循环动画停止，位移改为淡入或瞬时到位。弱设备上引擎类动效降级为静态图或 CSS 版本，首屏可读不依赖动效完成。

## 5. 验证

在真实页面看运行过程与关键帧，不只看静态终点；记起止状态、实际时长与掉帧情况；手机与桌面分别验证；减少动效模式下再过一遍。
