# 字体、配色、布局与材质的操作步骤

## 1. 选字体并排样张

1. 查现有 `@font-face`、文件、token 和可用字重。先比较已有字族，再决定是否新增。
2. 按用途取候选，实际下载/加载前打开官方展示和许可：

| 要比较的文字 | 先去哪里找 | 比较内容 |
| --- | --- | --- |
| 中文清秀 UI | [MiSans](https://hyperos.mi.com/font/zh/)、[思源黑体](https://github.com/adobe-fonts/source-han-sans) | Light/Regular 的菜单、按钮和混排 |
| 中文文学展示 | [霞鹜文楷](https://github.com/lxgw/LxgwWenKai)、[思源宋体](https://github.com/adobe-fonts/source-han-serif) | 两行标题和三行摘要 |
| 有性格的中文展示 | [得意黑](https://github.com/atelier-anchor/smiley-sans) | 少量标题，放入实际长标题比较 |
| 拉丁字族与配对参考 | [Google Fonts](https://fonts.google.com/)、[Typewolf](https://www.typewolf.com/) | 拉丁字母、数字与中文字面的搭配 |

3. 同一段内容排 2–3 个候选，UI 字先用 15/16px，标题先用 24/28px，正文先用 16px/26px。字重先比较文件真实提供的轻/常规档。
4. 字级表逐行填 font-family、文件路径/来源、实际字重、size px、line-height px、letter-spacing em、最大行数和回退栈。选择单值后再出图。
5. 长标题按语义换行，普通正文先用自然断行；检查行末孤字和数字单位拆开。说明正文过长先调列宽、摘要长度或展开方式，再改字号。
6. 加载后检查 `document.fonts.load()`、`document.fonts.check()`、字体资源状态与计算样式；用真实中文检查字形。只有计算 font-family 不能证明字形未回退；工具支持时查看实际渲染字体。
7. 记录文件字节、字重覆盖、缺字情况和许可。许可允许时才子集化；保留要求的名称、署名和许可。正文首屏优先加载一档，其他档按需要加载。

字级起始表在主文步骤 3；“清秀”通过轻/常规字重、字面、行高与图标样张比较，不转换成全页细小低对比文字。

## 2. 配色到每个角色

1. 取当前 token、Logo 和批准稿。列 page、surface、surface-raised、ink、muted、accent、accent-text、accent-soft、border、focus、danger。
2. 每个角色填确切 HEX/RGB/OKLCH 值及用途，列出原 token 到新 token 的映射。
3. 无现成规范时，可用下面的暖白/橙示例起一张样板；这是示例配方，品牌与批准稿优先：

| 角色 | 示例值 | 放在哪里 |
| --- | --- | --- |
| page | #FAF8F5 | 页面环境 |
| surface | #FFFFFF | 阅读内容面 |
| ink | #28231F | 正文 |
| muted | #71685F | 辅助说明 |
| accent | #EB5207 | 重点图形、装饰或经过检查的填充 |
| accent-text | #B43D08 | 小字号强调文字、链接 |
| accent-soft | #FFF0E8 | 选中背景 |
| border | rgba(80,53,35,0.12) | 内容分隔 |
| focus | #A83B0C | 焦点外轮廓 |

4. 分别测“正文/内容面、辅助/环境、链接/内容面、按钮文字/按钮背景、图标/实际背景”。橙色图形和橙色文字可用不同深度。
5. 透明面先按实际叠层合成，再算对比度。普通文字以 4.5:1 为常用 AA 检查线；大文字按 W3C 定义核对后用 3:1。
6. 在颜色样板同时放默认、选中、按下、禁用、焦点、失败；颜色随文字/形态共同表达状态。
7. 深色主题逐个重新定前景、底色、边缘和光线，重测对比度。

## 3. 先量版面再放内容

1. 记录目标 CSS 视口和批准图逻辑视口；图片尺寸与逻辑视口分开记录。
2. 在图稿里给各区域标 x/y/w/h，响应式区域同时标宽度比例、min/max 和伸缩规则。
3. 放入最长真实标题、摘要、按钮与资源预览。标出标题行数、可见对象数和主动作位置。
4. 先定外边距，再定列宽、列间距、卡片内边距。无既有值时用以下起始组合：

| 参数 | 桌面起点 | 窄屏起点 |
| --- | --- | --- |
| 页面边距 | 24/32px 二选一 | 16/20px 二选一 |
| 区域间距 | 24/32px 二选一 | 20/24px 二选一 |
| 卡片内边距 | 20/24px 二选一 | 16/20px 二选一 |
| 组内间距 | 8/12px 二选一 | 8/12px 二选一 |
| 卡片圆角 | 16/20px 二选一 | 16/20px 二选一 |

5. 输入吸底或固定栏要算高度预算并预留可滚动到末端的空间；记录 browse 的 min-height、overflow 和 dock 高度。
6. 版面先用 3–5 个区域块画出来。新候选比较实际区域位置、比例、字族、图像组织和控件关系；同一品牌允许固定色板，其他维度拉开差异。
7. 用户已批准的 Web 顶栏和客户端侧栏分别按对应 shell 量尺寸，共享内容组件在两个父容器都复核。

## 4. 按内容选图和裁切

1. 找项目品牌资产、内容图片、统一封面/头像组件和兜底。
2. 有封面传现有 URL 和 ID；比例取现有业务组件，样例封面保持可替换。
3. 填图片角色、来源、aspect-ratio、object-fit、object-position、加载占位与失败处理。头像取真实团队成员，角色关系图取实际节点/边。
4. 配图素材从官方或有明确许可的来源取；研究图和正式发布资产分别记录。生成能力用在已授权的设计稿和配图，实际产品数据取现有接口。
5. 背景图按文字安全区裁切，内容进入图面的位置加受控内容面；图稿用真实长文检查遮挡。

## 5. 液态玻璃：逐层写值

1. 先画五层：环境光/背景、透射表面、折射边缘、镜面高光、文字与操作。每层写面积、层级、alpha、圆角和事件穿透。
2. 在局部样板写初值，按批准图调整并记录单值：

| 层 | 起始值 | 操作 |
| --- | --- | --- |
| 透射面 | 白色 alpha 0.70–0.86、blur 8–16px | 选单值；背景可辨且正文清楚 |
| 内容保护面 | 白色 alpha 0.92–0.98 | 在长文区域调到可读 |
| 折射边缘 | 带宽 6–10px、位移 2–4px | 选单值；复用项目光学组件 |
| 高光 | 1px 边、白色 alpha 0.60–0.85 | 标方向，随层级变化 |
| 接触影 | 0 2px 6px rgba(70,42,23,0.05) | 贴近表面 |
| 环境影 | 0 12px 32px -18px rgba(70,42,23,0.20) | 调距离和扩散 |

这些是 Web 模拟的调参起点，原生平台材质使用对应原生能力。数字本身不能证明液态玻璃成立：图稿检查背景穿过边缘时的弯折、高光和厚度；页面阶段操作选中/展开并观察实际渲染。
3. SVG 位移用于边缘带，阅读内容层独立保护。只用 blur 的方案记录为透射/模糊，折射另列实现。
4. 项目已有 LiquidSurface/LiquidGlassRim 或同职责组件时从该组件调整；先在一个区域测试静止、选中、展开、背景变化，再扩展。
5. 记录 Chromium、Safari/WebView 支持。不可用时用 alpha 0.96 的稳定内容面和边缘高光，减少动效时保留材质静态终态。
6. 重效果记录地图尺寸、更新频率与实际测量；只在必要输入/尺寸变化时更新，离屏和空闲停止额外循环。
