# 图标选择、绘制和落地

## 1. 先列入口与现有资源

1. 查 Icon 组件、库、import 和调用者。
2. 列菜单、卡片标题、工具按钮的可见文字、动作、当前图标名和 SVG。
3. 同义功能共享图标定义；新视觉候选先局部比较，确定后集中改映射。

## 2. 去库里找具体候选

| 用途 | 来源 | 操作 |
| --- | --- | --- |
| 轻线编辑界面 | [Phosphor](https://phosphoricons.com/)、[Iconoir](https://iconoir.com/) | 搜功能动词，比较 Light/Regular 或原生 stroke |
| 常用业务图标 | [Remix Icon](https://remixicon.com/)、[IconPark](https://iconpark.oceanengine.com/) | 比较同族 outline；记录端点和主题 |
| 紧凑工具界面 | [Radix Icons](https://www.radix-ui.com/icons)、[Carbon](https://carbondesignsystem.com/elements/icons/library/) | 按原生网格/尺寸选择 |
| 跨库检索 | [Iconify](https://icon-sets.iconify.design/) | 用库前缀筛选，取官方 SVG 与许可 |

1. 把中文功能改写为动作/对象：模板先搜 template、structure、book；脑洞搜 idea、spark、fire。
2. 每个入口取 2–3 个候选，配相同文字排成一行比较；取到的图标必须实际展示，文字列表不足以选型。
3. 定下库、版本/提交、glyph 名、变体、来源、许可和本地资源路径。共用一套轮廓语言，补缺图标逐项对齐端点、转角和视觉重量。
4. 系统图标先复用成熟资源；少数品牌能力单独绘制，存入同一图标映射组件。

## 3. 校准尺寸与笔画

1. 先定角色尺寸：行内 18px、导航 20px、能力标题 28px；这是起点，按批准稿选实际档位。
2. stroke SVG 换算：`渲染笔画 = strokeWidth × 渲染尺寸 / viewBox宽度`。例如 24 viewBox 的 1.8 单位笔画，渲染 20px 时是 1.5px。
3. 填充轮廓路径的细/常规档由库定义；选 Light/Regular 原生变体，并量代表性直线的渲染厚度。给 fill 路径设 stroke-width 不能把它变成另一档轮廓。
4. 同行用实际文字比较：轻/常规 UI 字先试等效 1.25/1.5px；更重字先试 1.75/2px。选一个档位，保留库形状比例。
5. 光学大小按有墨区域比较；复杂图标与简单图标可各补 1px 尺寸，写入映射而非临时散落样式。
6. 定图标文字间隔 8/10/12px 中的一个。校中心时只改 SVG 自身 0/±1px offset，点击区域保持固定。

## 4. 核心能力画专属符号

1. 写一句实际语义，例如“选用一条故事方向”“借用书的情节结构”。
2. 画 2–3 个单色轮廓草图，保留一个主要轮廓与一个识别细节。
3. 从品牌标志提取能迁移的端点、弧线或切角，不复制 Logo 充当每个功能图标。
4. 用 24×24 或项目原生网格，设置 safe inset 2px、等效 stroke 1.5px 起步；记端点/转角。缩到最终显示尺寸再看孔洞、交叉和留白。
5. 放入真实菜单和标题局部图比较，再给用户审阅。批准后保存 SVG、含义、尺寸和状态参数。

## 5. 画四态并写点击因果

| 状态 | 要填的值 | 结果 |
| --- | --- | --- |
| 默认 | glyph、color、size | 入口可识别 |
| 选中 | indicator、color、aria-current/selected | 当前所在位置 |
| 按下 | scale/from/to/ms/easing | 即时回应，业务动作同步发出 |
| 焦点 | outline-width/offset/color | Tab 可见 |

1. 原地动作和路由入口用对应语义；陌生图标配可见文字，纯图标按钮设准确可访问名。
2. 同一功能在侧栏/卡片复用识别轮廓，尺寸与状态由角色 token 调整。
3. 点图标后的内容、选中指示或来源标签跟着变化；只让图标晃动不能代替结果反馈。
4. 连按、键盘、禁用、加载、返回都列入动作表。动效见 interaction.md。

## 6. 保存和验收

1. 将实际使用的 SVG 导入项目资源/组件，写明版本与许可；依项目资产规范处理 CDN 和内联。
2. 比默认/选中态的计算色值、尺寸、viewBox 与资源路径；检查资源加载和控制台。
3. 点每个受影响入口确认原 handler、参数、导航和焦点；可折叠侧栏检查 tooltip 与文字名称。
4. 生成图只用于选型：批准后对应到具体 SVG；图标稿与代码 glyph 映射逐项核对。
